# 🌞 MoonLight Solar Analysis

A data-driven analysis project for **MoonLight Energy Solutions**, focused on evaluating solar potential across multiple regions using exploratory data analysis, statistical modeling, and interactive dashboards.

---

## ✅ Project Overview

This project analyzes solar radiation and environmental sensor data to:

- Understand irradiance patterns (GHI, DNI, DHI)  
- Investigate environmental relationships (temperature, wind, humidity, pressure)  
- Assess cleaning impact on sensor performance  
- Compare solar potential across multiple countries  
- Support investment recommendations for high-potential regions
